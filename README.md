## For Deaf, Mute & Visually Impaired Users

### Tech Stack
- Frontend: React 18 + Tailwind CSS + ARIA
- Backend: Python FastAPI + NLP
- AI: OpenAI Whisper (speech) + TensorFlow (sign detection)
- DevOps: GitHub + Jenkins + Docker + Ansible + Terraform

### Accessibility Features
- Voice Assistant (text-to-speech)
- Speech Recognition (speech-to-text)
- Screen reader optimized (WCAG 2.1 AA)
- Sign language video lessons
- NLP-powered content adaptation
